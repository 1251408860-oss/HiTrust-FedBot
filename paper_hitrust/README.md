# `paper_hitrust/`

Reviewers should start from the repository root `README.md` when they want reproduction instructions. This directory is the paper-facing output surface rebuilt by the public reproduction scripts.

## Main Contents

- `runs/`: precomputed experimental run outputs
- `tables/`: JSON summaries for the released comparison results
- `figures/`: paper-facing figures regenerated by the public rerun scripts
- `figures_eaai/`: alternate exported figure outputs emitted by selected figure builders
- `artifact_manifest_20260324.json`: compact manifest of the artifact-side deliverables

## Reviewer Use

Reviewers who want to inspect delivered evidence without re-running the full pipelines should start from:

- `tables/`
- `figures/`
- `artifact_manifest_20260324.json`

The main full public rerun is `bash core_experiments/reproduce/reproduce_public_paper_bundle.sh`. The lighter `reproduce_reviewer_bundle.sh` path is only a sanity-oriented subset and should not be read as the full paper reproduction command.

The release-facing integrity metadata is stored alongside the paper artifact:

- `docs/ARTIFACT_STATUS_20260326.md`
- `docs/reviewer_bundle_sha256_20260326.txt`
- `core_experiments/reproduce/verify_artifact_bundle.sh`

The checksum manifest covers the static release surface only. Precomputed outputs under `runs/`, `tables/`, and `figures/` are intentionally treated as mutable derived evidence because the public rerun scripts rebuild them in place.
