# EAAI Highlights Draft (2026-04-02)

- We propose a trust-aware hierarchical federated GraphSAGE framework for topology-aware web bot detection under edge deployment constraints.
- Same-task public Ca-Bench validation uses matched 10-seed paired testing on `scenario_e` and `scenario_h`.
- On public `scenario_h + update_noise@0.4`, `condfloor` reaches `F1 = 0.9763`, `FPR = 0.0221`, and `0.0` retained poisoned clients.
- Centered Clipping reaches strong `scenario_h` predictive metrics (`F1 = 0.9777`, `FPR = 0.0218`) but still retains all `4.0` poisoned clients.
- Adaptive results place the proposed hardening variants on a more balanced poisoning-retention versus abstention frontier than official FoolsGold.
